description: 保留并转移长对话的哲学运动过程，形成一份紧凑的交接文档。
argument-hint: “下一轮会话将聚焦于什么？”
disable-model-invocation: true
---

为新会话编写一份紧凑的 Markdown 交接文档，并保存到用户操作系统的临时目录中，切勿保存到当前工作区。

不要以时间顺序概述对话内容，而要重建其内在的哲学运动。问问自己：用户最初试图理解什么？他内心关切着什么从而引导着他对问题的思考？哪些干预真正改变了问题的结构？用户的概念、立场和问题意识是如何深化的？模型如何理解该问题，哪些地方出错或被纠正，最终又达到了何种暂时性立场？哪些内容已被明确确认，哪些仍属模型的推断，探索在何处停止，用户接下来最可能做什么？

仅使用少量标题，并通过连贯段落展开每一部分。保留关键转折与稀有引述，删除重复内容与对话冗余。不要重复已存储于工件中的资料，而是引用其路径或 URL。对敏感信息进行脱敏处理。

如提供了参数，则将其视为下一轮会话的预期焦点。结尾应包含一条对用户下一步行动的具体预测，以及一个 `Suggested Skills` 部分，说明何时继续使用 `philosophical-clarification`、`philosophical-response` 或 `philosophical-handoff`。
