# Word Disclosure Error Index

这个文件是错误索引，不是 Moneta skills 入口。入口路由由 `ask-yanyu` 负责。

## 句式问题

- 先否定再解释：`成对否定转折`、`变体仍然要删`
- 作者解释写作安排：`元叙述`

## 用词搭配问题

- 词语搭配不自然：`链接词`、`气息`、`机械程度`、`场景`、`结果`、`动词搭配`
- 词源被写成口号或裁判：`词源`
- 中文释义没有例子支撑：`中文释义悬空`

## 意象问题

- 比较词没有动作支撑：`抽象比拟`
- 场景里出现半具体道具：`悬空的屋子`、`半具体的布`、`无关的晚餐`、`模糊状态`
- 漂亮句子替代具体物和动作：`漂亮抽象句替代具体威胁`

## 风格问题

- 中文像英文论述腔：`翻译腔`、`生硬口语`
- 比喻太怪或学究气：`怪隐喻`、`学究气隐喻`
- 形容词、文气、口号盖过动作：`空泛形容`、`空泛文气`、`口号结尾`、`文学正文被压成口号`

## 来源与改写问题

- 来源说明打断正文：`来源说明混进正文`
- 译文塞入解释：`译文解释性扩写`
- 外来意象挡住中文读者：`陌生意象未中国化`
- 改写故事没有独立站住：`改写场景被塞进解释句`
- 原文被切碎，靠白话补剧情：`原文引用碎片化`
- 后续情节不能继续说明 lemma：`重复抽象与无关后续`
- 词源故事被误当主场景：`词源故事误作显义场景`
- 故事改写附近混入英文资料感：`来源说明混进正文`、`陌生意象未中国化`、`故事改写混入英文`

## 近义词问题

- 比较轴偷换或差异没落到动作：`近义词比较偷换比较轴`
- 英语词被中文释义压住：`近义词比较偷换比较轴`、`近义词英语被括号化`
