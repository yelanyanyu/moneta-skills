# ANALYSIS-ZH

用于汉语单字、古汉语词、现代汉语词和翻译术语。汉语分析不能照搬印欧语词根法；先判断这个词靠哪条路成立。

分析时优先问：

- 单字：字形、训诂、早期用例和后来的义项扩展分别说明什么？
- 古汉语词：原文场合、句法位置、人物关系、制度背景和文气怎样影响词义？
- 现代复合词：它更像偏正、动宾、并列、主谓、述补，还是固定术语？
- 翻译术语：它从哪种外语概念转入汉语？汉语为什么用这些字承接它？
- 古义和现代义之间有没有断裂、借用、重释或制度变化？

拆字时要谨慎。每个字都必须在当前词义里实际出力；如果拆出来只是漂亮解释，就回到原文、用例或术语史。

短篇古文、短诗和可完整呈现的文本优先让原文自己站住。现代白话解释只补足阅读所需的背景，不替原文重新造一个词义。
