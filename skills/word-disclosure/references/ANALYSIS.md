# Word Disclosure Analysis Index

这个文件是分析索引，不是来源清单。来源去哪里找，读 [`SOURCES.md`](SOURCES.md)；拿到资料以后怎样理解词目，读这里。

## 分析目的

解释要清理习惯性的理解，让人不再把词语只当作标签、指令或操作。合适的艺术作品不是词义的例证；它要带人一步步走过具体处境，使词语重新显出它为什么这样被说出、被使用、被误解或被继承。

## 读取顺序

1. 判断词目的一等语言：英语 `en`、德语 `de`、汉语 `zh`。
2. 读取对应分析方式：
   - 英语、德语及主要印欧语词源路线：[`analysis/ANALYSIS-IE.md`](analysis/ANALYSIS-IE.md)
   - 汉语：[`analysis/ANALYSIS-ZH.md`](analysis/ANALYSIS-ZH.md)
3. 如果词目的来源跨语言，先按词目的一等语言确定正文分析方式，再把辅助语言作为材料进入正文。
4. 为当前词目选择一条主要 philological path（语文学路径）。不要把所有路径都塞进正文。

## 选择路径

优先问这个词靠什么成立：

- 词源链、同源词、前后缀或借用路径。
- 字形、训诂、古籍用例或复合词结构。
- 典故、制度、仪式、行业或宗教传统。
- 翻译术语史、音译、误用、讹传或跨语言重新安置。

路径只服务于正文理解。选错了就回到来源重新判断；不要为了凑整齐，把不合适的词也写成词根故事。

## 正文走向

正文通常顺着这些问题往前走，但不要把它们写成标题：

- 这个词被惯常理解为什么？
- 这种惯常理解会遮住什么：人物关系、身体动作、制度处境、情绪变化，还是词语来历？
- 哪个作品场景能够打断这种理解，让词目不再只是一个方便的标签？
- 作品里哪些动作、反应、停顿或后果，能一步步改变人对这个词目的看法？
- 词目是在怎样的世界里被说出、被使用、被误解、被借用或被继承的？
- 词源故事、命名故事和主要显义场景是否同一个？如果不同，正文先用哪一个破除惯常理解？
- 显义场景是否需要按 [`STYLE.md`](STYLE.md) 做本土文化微调，并补足相关原文上下文？
- 常见中文译法、近义词和同源词怎样回到作品里的动作，而不是只列成解释？
