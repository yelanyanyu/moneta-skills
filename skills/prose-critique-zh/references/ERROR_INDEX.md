# 中文文本坏味索引

这个文件只做索引，不写修正方法。需要方法和例子时，读取 `CORRECTIONS.md` 中的同名标题。

## 句式问题

- 先否定再解释：`成对否定转折`
- 作者解释写作安排：`元叙述`

## 用词问题

- 词语搭配不自然：`用词搭配`
- 动词或声音搭配别扭：`动词与声音`

## 意象问题

- 比较或判断没有动作支撑：`抽象比拟`
- 场景里出现半具体道具：`半具体意象`
- 漂亮句子替代具体物和动作：`漂亮抽象句替代具体威胁`

## 风格问题

- 中文像英文论述腔：`翻译腔与生硬口语`
- 比喻太怪、太泛或学究气：`怪隐喻与空泛形容`、`学究气隐喻`
- 人物心理和情绪前因没有写清：`空泛文气`
- 自然动作被拆得过细：`动作过度分解`
- 段落被收成口号或金句：`口号结尾`、`文学正文被压成口号`
