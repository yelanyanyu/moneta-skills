# ANALYSIS-ZH

用于汉语单字、古汉语词、现代汉语词和翻译术语。汉语分析不能照搬印欧语词根法；先判断这个词靠哪条路成立。

汉语词目不能直接拿外文概念或外国作品解释。先判定它是汉语内部发展，还是翻译术语、借词、日语汉字词回流、音译词或旧词承接新概念。若是翻译术语，要说明汉语为什么用这些字承接外来概念。

复合词若由两个关键汉字构成，不能只抽象拆字，也不能跳过拆字。先分别看两个字的字形、部件、声旁、训诂或早期义项怎样出力，再寻找能显出每个字动作的中文原文，最后判断合成词是否有自己的完整原文；只有两个字都在原文处境里站住，合成词的解释才不会变成漂亮拆字。

分析单字时，不能只找含有该字的名句。先看字形、声义、训诂或早期写法怎样支撑它的动作，再找最能显出这种结构的中文作品。作品里的场景要让字本身显出来：谁发出声音，谁承受，动作如何落到人、物、制度或处境上。

分析时优先问：

- 单字：字形、训诂、早期用例和后来的义项扩展分别说明什么？
- 古汉语词：原文场合、句法位置、人物关系、制度背景和文气怎样影响词义？
- 翻译术语：它从哪种外语概念转入汉语？汉语为什么用这些字承接它？
- 古义和现代义之间有没有断裂、借用、重释或制度变化？

拆字时要谨慎。每个字都必须在当前词义里实际出力；如果拆出来只是漂亮解释，就回到原文、用例或术语史。

短篇古文、短诗和可完整呈现的文本优先让原文自己站住。小说、戏曲和长篇散文中如果有短而精彩的原文片段，也优先引用关键原文，再用白话补足阅读所需的背景；不要先把原文改写成普通叙述，再拿改写稿解释词义。
