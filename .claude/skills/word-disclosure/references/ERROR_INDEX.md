# Word Disclosure Error Index

该文件是语言错误索引，用于查找文本中的 AI 味问题。`` 中的是具体的错误类型，你需要根据错误类型在 [CORRECTIONS.md](CORRECTIONS.md) 中查找对应的修正。

## 句式问题

- 先否定再解释，或反驳正文从未建立的理解：`成对否定转折`
- 作者解释写作安排或提示读者如何理解：`元叙述`

## 用词搭配问题

- 词语搭配不自然：`用词搭配`、`动词与声音`
- 词源被写成口号或裁判，或单一字书被当成最终解释：`词源`
- 中文释义没有例子支撑：`中文释义悬空`
- 中文复合词跳过字形、字素或构词关系：`字形分析缺席`

## 意象问题

- 比较词没有动作支撑：`抽象比拟`
- 文学里的空间词被解释成静态坐标：`静态空间化诠释`
- 场景里出现半具体道具：`半具体意象`
- 漂亮句子替代具体物和动作：`漂亮抽象句替代具体威胁`

## 诠释问题

- 把词义设成先在的固定实体或心理状态，再用“方式”“伴随”等语法分类替代对处境与关系的分析：`形而上学化以及传统语言学化`

## 风格问题

- 中文像英文论述腔：`翻译腔与生硬口语`
- 比喻太怪或学究气：`怪隐喻与空泛形容`、`学究气隐喻`
- 抽象关系被写成动作比喻：`怪隐喻与空泛形容`
- 抽象关系尾巴拖住句子：`怪隐喻与空泛形容`
- 抽象评价词替代具体差异：`怪隐喻与空泛形容`、`翻译腔与生硬口语`
- 评论腔动词替代文本细读：`怪隐喻与空泛形容`、`文本细读缺席`
- 自然动作被拆得过细：`动作过度分解`
- 形容词、文气、口号盖过动作：`怪隐喻与空泛形容`、`空泛文气`、`口号结尾`、`文学正文被压成口号`

## 来源与改写问题

- 来源说明打断正文：`来源说明混进正文`
- 译文塞入解释：`译文解释性扩写`
- 外来意象挡住中文读者：`陌生意象未中国化`
- 改写故事没有独立站住：`改写场景被塞进解释句`
- 篇幅可控的外文或中文原文被普通转述替代：`原文被转述替代`
- 原文被切碎，靠白话补剧情：`原文引用碎片化`
- 用叙事顺序、旁人反应或作者解释代替文本细读：`文本细读缺席`
- 后续情节不能继续说明词目，或结尾再次提示前文已经说明的关系：`重复抽象与无关后续`
- 词源故事被误当主场景：`词源故事误作显义场景`
- 故事改写附近混入英文资料感：`来源说明混进正文`、`陌生意象未中国化`、`故事改写混入英文`

## 近义词问题

- 比较轴偷换或差异没落到动作：`近义词比较偷换比较轴`
- 英语词被中文释义压住：`近义词比较偷换比较轴`、`近义词英语被括号化`
