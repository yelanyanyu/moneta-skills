# ANALYSIS-IE

用于英语、德语，以及主要走印欧语词源路线的 lemma。它也可临时服务法语、拉丁语、古希腊语等辅助来源语言。

分析时优先问：

- 现代 lemma 的来源词、早期拼写、同源词和借用路径是什么？
- 前缀、后缀、词根或复合结构是否真的参与当前词义？
- 词源动作和主要显义场景是否一致？如果不一致，哪一个更适合正文开头？
- 这个词有没有误用、音译、讹传、学术转写或跨语言重新理解？
- 现代常用义从哪一个动作、制度、人物姿态或文学场景延伸而来？

印欧语词源线索可以大胆追，但不要把词根当作裁判。词源资料只说明来路；正文仍要回到作品里的动作、人物反应和可验证引文。

作品材料进入正文前，先判断相关原文能否完整放入而不使篇幅明显膨胀。能放入时，直接使用英语、拉丁语、古希腊语或其他来源语言的原文，并配中文翻译，不要默认改写成中文故事。原文过长时，先选一段能独立成立的连续原文，用简短背景补足上下文。只有小说等长篇作品无法靠连续节选和少量背景交代清楚情节时，才改写故事；改写必须标明依据，不能冒充原文或翻译。
