# Support three first-class disclosure languages

Moneta will extend `word-disclosure` as one shared disclosure engine with three first-class disclosure languages: English, German, and Chinese. `SOURCES.md` remains the source index and keeps the brief cross-language search strategy; language-specific `SOURCE-*` files should stay compact and mainly list sources to search. Auxiliary languages such as Latin, Ancient Greek, and French remain available for etymology and source verification without becoming primary note directories.

**Consequences**

Word notes should move toward language-scoped directories such as `word/en/`, `word/de/`, and `word/zh/`. The shared style, correction, and error-index references remain cross-language because they govern Chinese explanatory prose, while source lists should split by language profile. `SOURCE-ZH` must cover single characters, Classical Chinese words, and modern Chinese words.
