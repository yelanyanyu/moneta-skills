# Word Disclosure Source Index

这个文件是来源索引，不是资料清单，也不写语言分析方法。它只说明如何判断该读哪些 `SOURCE-*`，以及跨语言搜索的共同规则。拿到资料以后如何分析词目，读 [`ANALYSIS.md`](ANALYSIS.md)。

## 读取顺序

1. 判断词目的一等语言：英语 `en`、德语 `de`、汉语 `zh`。
2. 读取对应来源清单：
   - 英语：[`sources/SOURCE-EN.md`](sources/SOURCE-EN.md)
   - 德语：[`sources/SOURCE-DE.md`](sources/SOURCE-DE.md)
   - 汉语：[`sources/SOURCE-ZH.md`](sources/SOURCE-ZH.md)
3. 如果词源或作品牵涉辅助语言，再临时查相关资料；辅助语言不改变笔记目录。
4. 先确认词源路线，再根据来源词、同源词、早期拼写、制度、仪式、行业或文化场景反查作品。
5. 得到候选作品后追原文。只找到作品名、简介或孤立句子时，不把它当作主要显义来源。

## 作品选择

选择主要显义来源时，先看作品是否贴合最早词源动作，再看艺术类型。不要只找出现现代词目的文本，也不要只找能解释现代义的文本；优先问来源词最早的动作、物、制度或姿态，在哪部作品里最清楚地站出来。

在同样可验证、同样贴合的情况下，优先级为：诗歌 > 散文 > 小说 > 其他类型的艺术作品。优先级服务于词源和场景，不要死板排序：如果小说比诗歌更贴合词源动作，就选小说。

短诗和短篇完整文本优先完整呈现，不做改写。外语文本按需要保留原文、英译和中译；中文译文按文学翻译处理，不做逐词对照。

## 搜索要点

- 现代词目只是入口之一。来源词、早期拼写、同源词和借用路径同样要查。
- 反查时同时找两类材料：来源词所在文化场景的资料，以及能读到原文的文学或艺术作品。
- 词源资料只能确认来路，不能替代作品场景。
- 找不到可验证资料时，直接说明暂未找到，不补模糊出处。

## 原文判断

把一个来源作为主要显义来源前，至少确认三件事：

- 能看到原文，短诗或短篇最好能完整看到。
- 作品本身适合展开这个词。
- 这个用法能帮助正文写出具体处境、动作或人物关系。

## 记录方式

properties 里只记录简短来源名：

```yaml
revelatory_sources:
  primary: "King Lear"
  candidates:
    - "King Lear"
earliest_source: "Middle English / Old French lineage"
```

正文里不写检索过程。只有当来源有不确定性时，才用轻一点的说法。
