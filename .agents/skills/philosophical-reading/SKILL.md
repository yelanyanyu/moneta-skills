name: philosophical-reading
description: 将哲学章节或段落重构为流畅、以问题为导向的阅读指南，使读者能够跟随作者的思想运动。
argument-hint: "粘贴一个哲学章节或段落。"
disable-model-invocation: true
---

进入作者的哲学立场，并以作者再次更清晰地阐述其论证的方式向读者讲述。不要模仿作者的句法、晦涩、翻译风格或修辞习惯。用流畅、自然的语言重写其思想，同时保留其哲学密度、概念区分和思想的运动方向。

让阅读由问题驱动。问自己：是什么根本困难促使这一文本开始运作？为什么作者不能再停留在既有的答案上？为什么这个概念必须在此处出现？每一个回应完成了什么，又产生了什么新的困难？哪些段落真正改变了思想的走向，哪些只是重复、遮蔽或拖延了它？到结尾时，最初的问题变成了什么？

重构章节的主要哲学转折，而不是逐段转述。压缩重复、离题、生硬的翻译、空洞的术语和不相关的材料，但绝不简化掉那些改变问题、引入决定性概念或改变作者立场的过渡。即使在原文未能清晰呈现时，也要保留思想的道路。

以自然衔接的段落展开指南。切勿将哲学内容排列为知识点、项目符号、编号步骤或其他列举结构。最终文本应读起来像作者对读者的持续讲述，而非关于作者说了什么的外部报告。

使用清晰的当代语言，并在有助于理解时引入植根于中国经验的生动例子。只保留具有实际概念分量的术语和引文；在术语首次重要出现时给出原文。在有助于读者回到原文的地方添加轻量级的位置标注。

保持正文流畅。对于实质性的重构、有争议的解释、文本错误、翻译困难或必要的学术背景，使用 Markdown 脚注来标注，而不是打断作者的声音。当解释依赖于文本、历史或术语主张时，请核实这些主张。

最后，重新连接驱动该章节的问题，展示每个问题如何源于前一个困难，以及最初的问题是如何被转化的。让读者带着文本真正打开的未解决张力离开。
