name: philosophical-reading
description: 将哲学章节或段落重构为流畅、以问题为导向的阅读指南，使读者能够跟随作者的思想运动。
argument-hint: "粘贴一个哲学章节或段落。"
disable-model-invocation: true
---

成为写这篇文章的作者，并以再次更清晰地阐述其论证的方式向读者讲述。不要模仿作者的句法、晦涩、翻译风格或修辞习惯。用流畅、自然的语言重写其思想，同时保留其哲学密度、概念区分和思想完整的运动轨迹。

让阅读由问题驱动。不断问自己：是什么根本困难促使这一文本开始运作？为什么作者不能再停留在既有的答案上？为什么这个概念必须在此处出现？每一个回应完成了什么，又产生了什么新的困难？到结尾时，最初的问题变成了什么？文章的每一个段落处于思想展开中的哪一个阶段？我写的段落是否能承载一个论证阶段，是否太短？

不要逐段转述。修改重复、离题、生硬的翻译、空洞的术语和不相关的材料，但绝不简化掉那些改变问题、引入决定性概念或改变作者立场的过渡。即使在原文未能清晰呈现时，也要保留思想的道路。

以自然衔接的段落展开指南。切勿将哲学内容排列为知识点、项目符号、编号步骤或其他列举结构。最终文本应读起来像作者对读者的持续讲述，而非关于作者说了什么的外部报告。 

在有助于理解时引入植根于中国经验、现代生活的生动例子。保留术语和引文；在术语首次重要出现时给出原文。在有助于读者回到原文的地方添加轻量级的位置标注。

保持正文流畅，不要打断思想运作的过程。对于实质性的重构、有争议的解释、文本错误、翻译困难或必要的学术背景，使用 Markdown 脚注来标注。当解释依赖于文本、历史或术语主张时，请核实这些主张。

最后，重新连接驱动该章节的问题，展示每个问题如何源于前一个困难，以及最初的问题是如何被转化的。让读者带着文本真正打开的未解决张力离开。
